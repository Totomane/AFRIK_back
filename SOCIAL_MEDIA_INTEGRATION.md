## 🔐 Authentication Flow

### 1. OAuth Connection Required
Users must connect their social media accounts through the OAuth flow:
- `/oauth/youtube/start/` - Start YouTube OAuth
- `/oauth/linkedin/start/` - Start LinkedIn OAuth  
- `/oauth/spotify/start/` - Start Spotify OAuth
- `/oauth/x/start/` - Start X OAuth

### 2. Token Storage
OAuth tokens are securely stored in the `SocialToken` model:
- `access_token` - For API requests
- `refresh_token` - For token renewal
- `expires_at` - Token expiration tracking
- `scopes` - Granted permissions

### 3. Automatic Token Validation
The API automatically:
- Validates token existence and activity
- Provides clear error messages for missing connections
- Returns connection URLs for easy OAuth setup

```python

result = youtube_service.upload_video(
```

### Upload Parameters
- **Required**: `title`, `file_path`
- **Optional**: `description`, `tags`, `category_id`, `privacy_status`
- **File handling**: Supports both absolute and relative paths
- **Validation**: File existence and format checking

### Backend Service Usage
```python
from services.youtube_service import YouTubeService

# Initialize with OAuth token
youtube = YouTubeService(user_token.access_token)

# Upload video
result = youtube.upload_video(
    video_file_path="/path/to/video.mp4",
    title="Economic Report - Nigeria 2025",
    description="Comprehensive analysis of Nigeria's economic outlook",
    tags=["nigeria", "economics", "2025", "forecast"],
    category_id="25",  # News & Politics
    privacy_status="public"
)

if result["success"]:
    print(f"Video uploaded: {result['video_url']}")
else:
    print(f"Upload failed: {result['error']}")
```
